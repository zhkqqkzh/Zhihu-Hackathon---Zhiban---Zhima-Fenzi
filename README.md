> 知乎黑客松 2026 · 校园新锐季 —— 知识炼金场赛道
>
> 读知乎遇到不懂的概念，**划一下**，当场在这篇回答的语境里讲明白；
> 这一划，也让下一个读到这里的人不再卡住——**你划过的、卡住的，它替你记着**，
> 聚合成答主看得见的「读者卡点报告」，再变成一段前置说明，价值回到社区。

## 项目亮点

> 知乎不缺优质长文，缺的是「读完」。深度学习、量子力学、医学——大量读者读到第三段就因为一个概念放弃了，这些知识「被写出来却没被吸收」。知伴补的正是这条空白数据。

### 1. 划一下，当场讲明白（选中即问）

在知乎回答页选中一个概念，弹出「问知伴」浮层，**流式返回**三层解释：

- **一句话定义**（不超过 40 字，让你秒懂）
- **为什么在这篇里重要**（紧扣上下文，不泛泛而谈）
- **前置概念链**（如「损失函数 → 梯度下降」，告诉你读之前需要先了解什么）

### 2. 你卡住的地方，也让别人少卡一次（卡点飞轮）

这是知伴最独特的价值——把每个读者「卡住」的瞬间量化、聚合、回馈社区：

```
读者划词卡了一下 → 匿名上报「概念名 + 段号」
  → 侧栏「本篇卡点 TOP3」：别的读者实时看到「N 人也卡在这」
  → 答主视角报告：作者看到读者卡在哪 → 补一句前置说明 → 下一任读者不再卡
```

数据三源在界面**如实标注**：演示环境数据 / 你的上报 / 社区上报，绝不把预置数据冒充真实统计。

### 3. 全文预扫描——读之前就知道哪里会卡

打开知乎回答即自动预扫描全文，抽取 5–15 个专业概念，用 CSS Custom Highlight（零 DOM 变更）淡色波浪线标注。概念名逐字照抄原文，不做任何改写——否则前端匹配不到会变成「幽灵标记」。

### 4. 卡点聚合 & 答主视角

答主视角页（`#/creator`）为答主提供：
- 当前回答的读者卡点报告：人次、占比、段落位置、来源标注
- 「在开头补一句前置说明」的具体建议，可一键导出为 Markdown 草稿

答主拿到草稿后自行补进回答，价值由此回到社区。

### 5. 每周复盘——你忘了，它替你记着

不打开任何中心页面，距上次复盘 ≥7 天时自动推送一张极简复盘卡：
- 本周问过多少概念
- 掌握率（unvisited → fuzzy → passed 三档）
- 最该补的 3 个概念

零配置、纯本地、不调模型。

### 6. 我的笔记卡片——真实的出口

单概念或导读都可「存为我的笔记卡片」，本地存储，一键导出 `.md`。包含：概念名、定义、本篇语境、原文引用、来源链接、时间戳。

**这是真实的笔记，不是模拟的发布**——知乎官方接口只读，知伴不做「一键发布到知乎」。

### 7. 知识薄弱方向推荐阅读

根据你的学习诊断结果（薄弱主题 + 概念缺口），从所有文章中推荐覆盖薄弱概念的文章。每条推荐显示：
- 覆盖了多少薄弱概念
- 具体帮你补上哪些概念
- 点击即可跳转文章页

### 8. 个人中心完整闭环

独立页面（`#/profile`），包含：
- **首页**：学习数据概览、卡点统计、功能导航
- **学习足迹**：近三篇文章、近三个概念、学习方向思维导图（显示每个方向的文章数量）
- **收藏夹体检**：分析知乎收藏夹内容，按主题分类、逐条点评（需插件环境 + 知乎登录态）
- **知识卡片**：已积累的概念卡片复习
- **推荐阅读**：基于薄弱方向推荐文章

### 9. 非概念三层拦截——划「的」不再浪费模型调用

选中「的」「了」「然后」等无意义片段时，知伴会先经过三层拦截（确定性短路 + 词表过滤 + 判定式 prompt），确认是虚词/标点/通用词时才返回非概念结果，不浪费模型调用。不会编出一段假装有定义的解释。

## 架构

```
知乎页面（插件注入）──→ 腾讯云 SCF（模型调用/代理）──→ 智谱 GLM
                   所有用户数据只存浏览器本地
```

**关键设计原则**：
- **没有数据库、没有自有服务器**。模型密钥只在 SCF 环境变量里。
- **知乎接口只是可选增强，不是核心依赖**：在未配置密钥或无扩展注入时一律静默降级；核心选中即问与全文标记仅需页面文本 + LLM。
- `/ask` 支持 `stream:true`：SCF 把 GLM 的 SSE 增量原样透传，前端边收边渲染。

### 目录结构

```
├── extension/             # Chrome MV3 插件（核心交付）
│   ├── manifest.json
│   ├── src/
│   │   ├── content.js         # 知乎适配层（CSP 绕行、划词、SPA 归属判定）
│   │   ├── background.js      # 请求中转 + 知乎 API 白名单转发 + 流式端口
│   │   ├── profile-page.js    # 个人中心独立页
│   │   └── profile-zhihu.js   # 知乎账号卡 + 收藏夹体检
│   ├── profile.html
│   ├── build.mjs          # esbuild 打包
│   └── dist/              # 构建产物（git 忽略，npm run build:ext 生成）
├── demo/                  # 插件能力镜像的前端代码（本地开发使用）
│   ├── index.html
│   ├── assets/
│   └── js/
│       ├── core/          # 环境无关共享模块（匹配/高亮/诊断/存储/笔记等）
│       ├── app/           # 应用层（路由/选中/浮层/侧栏/个人中心等）
│       └── data/          # 3 篇互链 ML 文章
├── server/                # 本地开发服务器
├── scf/                   # 腾讯云 SCF 后端代码
├── scripts/               # 脚本与测试
└── package.json
```

## 快速开始

```bash
npm install          # 安装构建依赖（esbuild）
npm run build:ext    # 打包插件到 extension/dist
```

构建完成后，打开 `chrome://extensions` → 开启开发者模式 → 加载已解压的扩展程序 → 选中 `extension/` 目录。

完整部署指南见 [DEPLOY.md](./DEPLOY.md)。

## 已知限制

- **移动端不做**：知乎的阅读主场景在手机，而移动端无法承载 MV3 扩展与划选交互，这是形态天花板
- **收藏夹体检依赖插件环境**：需读知乎登录态
