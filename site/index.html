你在知乎读过多少篇文章？又真正学会了其中哪些知识点？

多数人答不上来——不是读得少，是读过的都散掉了：收藏了没读，读完了没记住，记住的连不成片。 知伴是一个属于你的阅读个人中心：读过的回答、卡住的概念、没读完的篇数、该补的缺口，全部沉淀在一处—— 看得见、回得去、带得走。划词解释只是它的入口，负责让你在原文里读得下去。

它解决什么

信息不缺了，缺的是把读过的变成自己的

长文随手收藏、干货划个重点，这套动作我们都很熟练——真正没被解决的，是关掉页面之后的事。 碎片化的不是内容，是我们的阅读：读过就散，散了就忘，忘了下次还从零开始。

收藏 ≠ 读过

收藏夹成了终点站

收藏是「稍后读」的许愿，不是读完。攒了几百篇，却没有一处告诉你：哪几篇你其实停在第三段。

读过 ≠ 记住

没有回访，就没有积累

当天看懂的概念，一周后只剩模糊印象。没有到期提醒、没有掌握程度，读过的每一篇都在原地归零。

懂的 ≠ 连得上

概念是一个个孤岛

单个词查得到，但不知道它依赖什么、又被谁引用。缺前置就先卡住，知识拼不成体系。

卡住 ≠ 被看见

最难的地方无人知晓

卡顿发生在关掉页面之前的一瞬间，既没被记录，也没留给答主——同一个概念，一批又一批人重复卡在这里。

主功能

个人中心：读过的、卡住的、该补的，都在一处

它不催你多读，只负责把已经读过的收好：8 个模块合起来，回答三个问题——我读了什么、我卡在哪、我接下来该补什么。 零注册、无账号，所有记录只存在你自己的浏览器里。

首页 先讲最重要的那句

你卡住的、别人也在卡的，以及「你有 N 篇长文没读完——不是你的问题，是缺了前置」，一句话把处境说清。

我的贡献 你帮到了谁

本机上报的卡点、覆盖的回答、涉及的概念，配一张「卡点地图」与时间线：你标的每一处，在所属回答里排第几卡点、多少人同卡。

收藏体检 收藏里的真问题

把收藏与困惑打通，回答的是「这些收藏里，哪些概念你其实没真懂」。插件环境下还会读取登录态收藏夹，做一次完整体检。

推荐阅读 收藏夹高分 + 学习盲区

从收藏里挑出真正值得精读的高分文章，再补一句「这些概念你碰到过但还没走通」，读什么不用再凭感觉。

学习数据 把碎片连成体系

时间轴看成长轨迹，思维导图看概念之间的依赖与缺口（三色节点区分学过几篇、只学过一篇、还缺的前置），再给知识卡片与方向建议。

我的笔记 真实的出口

每个概念、每篇导读都能存成卡片：定义、本篇语境、原文引用、来源链接、时间戳，一键导出 .md。不做「模拟发布」。

学习复盘 按记忆曲线回来

掌握率、待巩固、待回访一目了然；到期概念按 1→3→7→15 天间隔提醒，点一下就跳回原文那一段。不用打开任何中心页也会收到推送。

阅读足迹 读过什么，一目了然

读过的回答、读完的比例、展开过多少概念、提问几次、生成过哪些导读——全部可点回原文，接着上次的地方继续。

数据从哪来

个人中心的每一格数字，都来自你在原文里的一次划选

它不需要你额外打卡、填表、做笔记——那些坚持不下去的动作，我们都不要求。 你只要在读不懂的地方划一下，剩下的记录、聚合、回流，它替你完成。

辅助能力

划词解释：让你在原文里读得下去

它是入口，不是终点。解释完的每个概念会自动进个人中心，成为学习数据与复盘清单的一部分。 这一环不依赖任何知乎接口，没有扩展注入也能 100% 工作——这是产品的底线。

选中即问

划选概念即弹「问知伴」，流式返回三层解释：一句话定义 / 它在本段的作用 / 你可能需要先了解的。判定不是概念时如实说明，绝不编一段解释。

全文概念预扫描

打开文章即标出本篇 5–15 个专业概念，划之前就知道哪里会卡。原生高亮、零 DOM 变更，幽灵标记率实测 0.0%。

看山提问

基于问过的概念生成一道自测题，答完即评并补充解释——把「好像懂了」变成「确实懂了」，掌握状态随之更新到个人中心。

快速开始

评委现场，三步跑起来

  1. 装依赖 — 在仓库根目录执行 npm install（仅 esbuild / express，运行时零三方依赖）。
  2. 打包扩展 — npm run build:ext 产出 extension/dist/；MV3 禁止远程代码，跳过这步会加载失败。
  3. 加载 — chrome://extensions → 开发者模式 → 加载已解压的扩展程序 → 选仓库里的 extension/ 目录。
# 只想看个人中心，不装扩展
npm install
npm run dev            # http://localhost:8787 → 顶栏进入「个人中心」

# 浏览器插件形态（完整体检：含知乎登录态收藏夹）
npm run build:ext      # 产物在 extension/dist/
# chrome://extensions → 开发者模式 → 加载已解压的扩展程序 → 选 extension/

打开任意知乎回答页，选中正文里的概念即可看到「问知伴」浮层；读过的、卡住的，会自动出现在个人中心。 Demo 站没有扩展注入时，收藏体检会用本地阅读足迹压出「该补信号」，不会空着。
